# 30 дней дисциплины — Android PWA

## Что внутри
- 30 отдельных дней с навигацией.
- Галочки для пяти намазов.
- Счётчики прочитанных страниц и выученных единиц.
- Гибкие отметки тренировок: верх тела, корпус, ноги.
- Сон с автоматическим расчётом длительности.
- Питание, вес, рост и заметки.
- Локальное сохранение в браузере.
- Экспорт/импорт резервной копии JSON.
- Поддержка установки на главный экран и офлайн-кэша после первой загрузки.

## Как установить на Android
Для установки как приложения сайт должен быть доступен по HTTPS.
1. Распакуй архив на компьютере.
2. Загрузи содержимое папки в статический хостинг с HTTPS (например, GitHub Pages или Netlify).
3. Открой опубликованный HTTPS-адрес в Chrome на Android.
4. Нажми меню ⋮ → «Установить приложение» или «Добавить на главный экран».
5. Открой приложение и проверь сохранение отметок после закрытия.

## Важно про данные
Данные хранятся в localStorage браузера на этом устройстве. Не очищай данные сайта/браузера, если не сделал резервную копию. Для переноса или дополнительной защиты регулярно используй «Экспортировать резервную копию».
